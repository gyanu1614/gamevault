# Seller CTA backdrops

Drop a per-game background image here to fill the seller banner (the
"Got {Game} to sell?" band on values / calculator / blog pages).

- **Filename:** `<gameSlug>.png` — e.g. `steal-a-brainrot.png`, `adopt-me.png`
- Any web image format works if you keep the `.png` name, but PNG/JPG recommended.
- **No file for a game?** The banner falls back to the clean forest scrim — no error.
- The image is shown at ~28% opacity behind a left-weighted dark scrim, so busy
  art still keeps the text legible. Landscape/wide images look best.

This is a SEPARATE folder from `public/cta-heroes/` (the BUY banner backdrops),
so your buy and sell art can differ per game.
